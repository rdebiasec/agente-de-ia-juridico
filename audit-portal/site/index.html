3 · Documentación rápida

Ruta del editor

Use el breadcrumb: Equipo → Agente → Prompt/Skills/Guardrails. Cada clic baja un nivel; el notepad muestra solo el ítem activo.

  • Prompt: quién es, qué hace, límites y tono.
  • Skills: procedimientos reutilizables (pueden compartirse).
  • Guardrails: filtros de entrada, salida y tools.

Reglas del despacho

  • No inventar sentencias, radicados ni normas.
  • Todo lo accionable requiere aprobación humana.
  • Prompt sistema = reglas compartidas de toda la firma.
  • Cambios quedan auditados con nota e historial.

Flujo recomendado

  • 1. Elija equipo y agente en la ruta.
  • 2. Ajuste Prompt (Función primero).
  • 3. Revise Skills y Guardrails críticos.
  • 4. Guarde versión y pruebe en el chat del abogado.

Dónde está cada cosa

  • COORDINACIÓN: Gerente del Caso (POC).
  • ESPECIALISTAS: cronología, tipicidad, ruta, víctimas, evidencia, audiencias…
  • CALIDAD: control jurídico antes de entregar.

Fuente operativa: firma virtual con HITL · canales web (activo) y Slack · WhatsApp no implementado.
